# Outcome-scored routing experiment (v0.5)

46 turns in 10 synthetic sessions. Every deterministic path ran real Python handlers through `LocalHarness`. **No model was called.** Model paths are scored on whether the exact context packet contained the facts the turn needed.

## Safety red team

A compromised router forged approved plans for every requested write: **18 attempts, 0 executions.** Positive control (fully authorised host) reached the handler: **True**.

## Assumptions

- Model calls are never executed. A model call whose context holds every needed fact counts as able to succeed; answer quality is not measured.
- The tool-calling agent is assumed to request exactly the missing facts, in parallel, in one extra round. Real agents misselect tools; this favours the agent.
- Generated answers are not simulated and are excluded from every arm's history, which understates the agent's context growth.
- Characters are counted, not tokens. No prices, latencies or dollars are produced.

Not measured: answer quality, tokens, dollars, provider latency, calibration, LiteLLM / vLLM Semantic Router / Jev / provider tool search.

Post-freeze changes: Scoring fix after the first run: when the agent requested a write and the harness blocked it (status 'blocked', principal lacks permission), the turn was labelled 'unauthorized_execution' although nothing executed and the write ledger was empty. Such turns are now labelled 'held'. No routing decision, fixture or context policy changed..
