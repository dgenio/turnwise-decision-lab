# v0.7 exit-gate study

Generated by `python -m turnwise_lab.v07.bench --report` from the recorded traces in `reports/v07/traces/`. CI regenerates this file and fails on any difference. CI does not re-run model inference.

**Question.** Does it matter more *who chooses each step* (rules, a trained decision head, an LLM agent) or *whether the host checks the exit* against an evidence contract? Three v0.6 controllers run unchanged, each with and without the exit gate, plus a contract planner that asks no model to choose.

**Scale.** Every model is the pinned v0.6 local stack. The "heavy" model is Qwen3.5-0.8B (q4). Nothing here is evidence about a capable agent.

**Freeze.** The scorer, the gate, the controllers, the predictions and the locked task file were frozen on 2026-11-18T22:23Z (manifest of 31 file hashes, parent commit `2e619b86`) before any arm ran on the locked set: [pre-registration](../../docs/preregistration-v0.7.md), [manifest](../../docs/v07-freeze.json). The implementer had not read the locked tasks. What an independent review changed before the freeze, and what was found after it, is in [`docs/v07-self-review.md`](../../docs/v07-self-review.md).
