Route the work, not just the model · decision-driven agent control

One user turn, many decisions, each one made after the last result came back.

A trained lightweight decision model picks the agent's next operation: a tool, a workflow, a light or heavy generation model, finishing with verified data, or a clarifying question. An independent host validates every proposal before it runs, and each result feeds the next decision. Below, the same request handled by this loop and by a conventional agent whose whole loop is the heavy LLM.

Held-out results (30 tasks written by an independent agent)

Success is checked from the outcome alone: the right kind of reply, the needed evidence actually gathered, answer content, and no forbidden or executed write. Cost comes after success. Latency is local CPU time, and no provider was billed. Status: exploratory and inconclusive. "Heavy tokens" counts heavy generation only, including cache-reused prompt tokens. Counting every token the 0.8B model actually computed, including the controller's own scoring, the decision-driven loop processed more tokens than the heavy-only agent; its saving is in time, mostly decoding (audit).

What is real and what is not

Observed

  • Every decision in these traces is real local inference by turnwise-dm. Its inputs are a trained head, one cached scoring pass of Qwen3.5-0.8B and s1-llm-auto-router; the operation comes from that inference, not a fixture.
  • Every tool and workflow really ran through the host's permission harness, against a synthetic world.
  • Every generation is real output from Qwen2.5-0.5B (light tier) or Qwen3.5-0.8B (heavy tier and heavy-only agent).
  • Token counts come from each model's tokenizer; latencies were measured on the CPU named above.

Not shown or not measured

  • Hosted decision services (OpenAI Decisions, Jev): adapters exist, but none was called. There were no credentials and no approved spend.
  • Frontier models. "Heavy" here is a 0.8B model on CPU, so the conclusions hold at this scale only.
  • Dollar costs, hosted latency, and answer quality beyond the lexical checks.
  • This page replays recorded traces and runs no inference in your browser.
